# 資格スケジュール帳

資格試験の **試験日と申込期間** をまとめたサイトです（GitHub Pages で公開）。

- **締切が近い**：いま申込できる試験を締切順に表示。残り日数つき
- **一覧**：分野ごとの全資格と各回の日程
- **カレンダー**：申込開始・申込締切・試験日を月表示
- **受験予定**：☆を付けた回とメモ。`.ics` でスマホのカレンダーに取り込める

右上の **受験地** で都道府県を選べます（初期値は愛知県）。危険物取扱者・消防設備士・日商簿記1級など、受験地で日程が変わる試験はその県の日程に切り替わります（現在は愛知県のデータを収録）。

☆・メモ・合格済み・受験地はブラウザに保存されます。⚙（設定）から GitHub のトークン（gist 権限のみ）で接続すると、シークレット Gist を通じてほかの端末と同期します。

各回には **合格発表日** と **受験料** を表示し、「受験予定」タブで☆を付けた回の受験料合計を出します。

## 締切の通知

`.github/workflows/notify.yml` が毎朝 7:03（日本時間）に、同期用 Gist の☆を読んで通知します。

- 通知するもの：申込開始日、申込締切の7日前・3日前・前日・当日、試験の7日前・前日、合格発表日
- 通知方法：このリポジトリに Issue を作ってあなたに割り当て（GitHub のメール・アプリに通知が届く）、すぐ閉じます
- 設定：Settings → Secrets and variables → Actions → **Variables** に `STATE_GIST_ID`（サイトの⚙に表示される Gist ID）
- 任意：スマホの [ntfy](https://ntfy.sh/) アプリにも送るなら、**Secrets** に `NTFY_TOPIC`（推測されにくいトピック名）を登録し、アプリで同じトピックを購読

## 自動取り込み（GitHub Actions）

`.github/workflows/update-data.yml` が毎日 6:17（日本時間）に `scripts/update_auto.py` を実行し、公式サイトから日程を取り込んで `data_auto.js` を更新・コミットします。

- 危険物取扱者・消防設備士：消防試験研究センターの全国日程PDF（全都道府県）
- TOEIC L&R：IIBC の日程ページ

取り込みに失敗したときは前回のデータを残します。Actions タブの「試験日程の自動取り込み」→ Run workflow で手動実行もできます。

## 日程の更新方法（手動）

データはすべて `data.js` にあります。新しい回を足すときは該当資格の `sessions` に1行追加するだけです。

```js
{ label: "令和9年度 前期", apply: ["2027-10-05", "2027-10-23"], exam: ["2027-10-16", "2027-11-22"], detail: "補足" },
```

- `apply`：申込期間 `[開始, 終了]`（未発表なら `null`）
- `exam`：試験日 `[開始, 終了]`（1日だけなら同じ日付を2回）
- 通年受験の資格は `anytime: true`、都道府県ごとの資格は `regional: true`
- 合格を区分ごとに記録する資格は `parts: [[id, 表示名], …]`。回で受けられる区分が限られるときは回に `parts: [id, …]`
- 受験地限定の回は `pref: "愛知県"` を付ける。`fallback: true` の回は、選んだ受験地のデータがないときだけ表示

情報確認日：2026-10-10。日程は変わることがあるので、申込前に各公式サイトで必ず確認してください。

動作確認用に `?today=2027-01-20` のように日付を指定して表示を試せます。
